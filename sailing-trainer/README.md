# ⛵ Парусный тренажёр (Sailing trainer)

Веб-приложение для повторения знаний яхтсмена-швертботиста. Интерфейс на русском, английские термины показаны рядом (их можно скрыть кнопкой «EN» и подсматривать по нажатию).

**Разделы**

- **Словарь** — ~150 терминов (корпус, рангоут, такелаж, паруса, курсы, манёвры, ветер, узлы, безопасность) с определениями на RU/EN.
- **Карточки** — интервальное повторение (система Лейтнера): RU→EN, EN→RU, знак/описание→термин. Колоды: термины, знаки и сигналы, команды.
- **Тесты** — выбор ответа: определения, знаки, звуковые сигналы, команды, ситуации на воде.
- **Устройство лодки** — интерактивная схема швертбота (вид сбоку и сверху): изучение, «найди на схеме», «назови деталь».
- **Знаки и сигналы** — МАМС регион A (латеральные, кардинальные и др.), знаки внутренних водных путей CEVNI (на них основаны польские правила), звуковые сигналы с проигрыванием, флаги МСС.
- **Манёвры и команды** — оверштаг, фордевинд, «человек за бортом», опрокидывание, отход/подход, остановка; упражнение на порядок действий.
- **Правила расхождения** — случайные ситуации (разные/один галс, обгон, моторная/гребная лодка, большое судно на фарватере) с объяснением правила.
- **Симулятор** — вид сверху, упрощённая физика швертбота. Управление кнопками: румпель «От себя / К себе» (или упрощённо «Привестись / Увалиться»), «Выбрать / Потравить» для грота и стакселя, «Смена борта» после каждого поворота (экипаж пересаживается, стаксель перекидывается; если забыть — стаксель обстенён, экипаж кренит лодку на подветренный борт). Состояние парусов: работает, полощет, перетянут, обстенён, в тени грота. Вымпельный ветер, крен и опрокидывание, порывы. Мир: берег, марина с фарватером (МАМС A), мель с кардинальными знаками, знак отдельной опасности, маяки с характеристиками огней, ночной режим с ходовыми огнями, другие суда, которые расходятся по правилам МППСС/CEVNI. 13 заданий: курсы относительно ветра, лавировка, слалом с поворотами фордевинд, подход к бую, «человек за бортом», треугольная дистанция, свежий ветер, выход из марины, заход и швартовка, кардинальные знаки, расхождение с судами, ночной заход по огням.

Работает на телефоне и компьютере, после первого открытия — офлайн (PWA, можно «Установить на главный экран»). Прогресс хранится в браузере (localStorage).

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # unit tests: physics, rules, missions, content
npm run build      # production build to dist/
```

Стек: TypeScript + Vite, без UI-фреймворка. Физика симулятора (`src/sim/physics.ts`) — чистые функции, покрыты тестами. Контент — в `src/data/*.ts`: чтобы исправить термин или команду, достаточно поправить текст там.

## Публикация на GitHub Pages (бесплатно)

Workflow `.github/workflows/sailing-trainer.yml` при пуше в `main` прогоняет тесты, собирает приложение и публикует его.

1. Один раз: в репозитории **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. Влить изменения в `main`. Через минуту-две приложение будет доступно по адресу `https://<владелец>.github.io/<репозиторий>/`.

GitHub Pages бесплатен для публичных репозиториев; для приватного нужен платный план GitHub.

## Оговорки

Это тренажёр для повторения, а не официальный учебник: изображения знаков упрощены, а физика приближённая. Перед экзаменом сверяйтесь с официальными правилами (МППСС-72, CEVNI / польские правила плавания по внутренним водным путям).
